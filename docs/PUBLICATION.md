# Publication scope

This repository is a source and example distribution of the local studio as inspected on 1 November 2026. The running installation is kept separate and unchanged.

## Included

All application source files, existing tests, launch scripts, authored documentation, reusable script kits, examples, artwork, vendor notices, and sample verification evidence are included. Cartoon Studio includes its `demo` and `coffee-demo` render folders. Stickman Studio includes its original example collection and narrator reference assets. `MANIFEST.json` records each packaged file's size and SHA-256 digest (excluding the manifest itself and Git metadata).

## Kept local

Downloaded model weights, Python environments, runtime installations, generated caches, logs, mutable queue/job state, private production projects, uploaded media, and Shorts account data are not distributed. In particular, YouTube OAuth client configuration, access tokens, and refresh tokens must never be committed. These are operational data, not missing implementation. Install dependencies and models separately using the setup guide and their upstream terms.

The complete production archive remains in the original local installation. Published sample verification reports describe earlier runs; they are not evidence of a fresh full model-generation run on a clean computer.

## Rights and provenance

Existing licenses and third-party notices are preserved. Model weights are not relicensed by this repository. Refer to the model publisher's terms before downloading or redistributing weights. Research scripts retain their source notes; illustrative visuals should not be mistaken for empirical evidence.
