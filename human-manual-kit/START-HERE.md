# Human Customer Support — production guide

Upload **SCRIPT.md** in Cartoon Studio using **Upload full script**. Review the imported scenes, choose **Add imported scenes to queue**, select these twelve scenes and choose **Render selected**. Select only the scenes you want rendered if older work is also in the queue.

The script includes cast, set prompts, props, scene direction, supported acting controls and a clearly marked Dialogue section. Research and editorial notes are outside the spoken sections. All eight cast members are already installed: Milo, Nova, Ellie, Malik, Jun, Anaya, Mira and Rowan.

Twelve standalone scenes use two reusable background prompts and a supplied clean explainer stage. Cartoon Studio can generate the two ordinary sets as needed and reuse them. No new character artwork, animated props or physical demonstrations are needed. The script is 720p landscape with captions. No app changes are required.

At 155 spoken words per minute plus the marked pauses, the 1,215-word script estimates to 8 minutes 20 seconds before cards. Actual generated speech can differ. Allow roughly 8–9 minutes overall, depending on delivery and your edit.

Join the separate rendered clips in your editor. Add opening and source cards there if wanted; no automatic joining is requested. Use the links in RESEARCH.md in the video description. Keep the qualifications in scenes 3–5 if trimming. For short clips, pair each misconception with its correction.

The dialogue folder contains a plain-text copy of each scene for manual reference. SCRIPT.md is the full-script upload file; the dialogue-only files omit cast and set metadata.

No video, voice or set generation was run while preparing this kit. Existing projects and the render queue were not edited.
